# 🧩 Sudoku Galaxy – Java DSA Project

An interactive Sudoku game built using **Java** and **JavaFX** as a university **DSA (Data Structures and Algorithms)** project. This project demonstrates the practical application of core data structures in a puzzle-based game environment.

## 🎯 Features

- ✅ 9x9 Sudoku Grid
- 🎮 Game Modes: Classic & Daily Challenge
- 🎵 Sound FX on Button Hover
- 📖 "How to Play" Instruction Guide
- ❌ Mistake Counter (Game Over after 5 wrong attempts)
- ⏱️ Timer with threading
- 🔄 Continue/Restart Game Options
- 🎬 Splash Screen with Animation and Tagline

## 🛠️ Technologies Used

- **Java**
- **JavaFX**
- **DSA Concepts**:  
  - 2D Arrays (for the Sudoku grid)  
  - Back Tracking (to validate entries)    
  - Timer & Threads (for countdown)

## 📌 Conclusion

This project enhanced my understanding of Java, GUI development, and core data structures by applying them in a fun, interactive Sudoku puzzle. It also helped me explore real-world implementation of game features using algorithms.
